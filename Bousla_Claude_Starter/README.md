# Bousla — Claude Code Starter Pack

Files:
- `CLAUDE.md`: working instructions.
- `docs/project-context.md`: context and vision.
- `docs/implementation-plan.md`: phased plan.
- `docs/ethics-privacy.md`: privacy principles.
- `docs/demo-script.md`: draft demo flow.
- `docs/surveys/survey-design.md`: survey overview.

## Use
Copy the files into the root of the Bousla repository preserving the docs structure. Open Claude Code at the repository root and ask it to read `CLAUDE.md`, `docs/project-context.md`, and `docs/implementation-plan.md`. Begin with Phase 0 (repository reconnaissance), not a blanket implementation request.

These documents describe a proposed direction and do not imply features are implemented.
